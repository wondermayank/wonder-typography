# Wonder Typography

**Free typography studio with 1,000+ designed text styles, animated typography and flower-style premium designs, by [Wondermayank](https://wondermayank.in/).**
Type your text, pick a style, add motion and download it in one click. No account, no watermark.

**Live site:** [typography.wondermayank.in](https://typography.wondermayank.in/)

---

## What's inside

| Section | What you get |

| **Index** | 1,000+ ready-made typography designs to browse and use |
| **Elements** | 10+ animated typography styles |
| **Premium** | 30+ flower-style animated typography designs |
| **Anime** | Coming soon |

## Features

- **Live preview** that updates instantly as you edit your text
- **Custom text styling**: font size, letter spacing, line height and custom stroke (single or double outline)
- **Live animation styles** such as lightning, aura, flame embers, sakura petals, shimmer, float and glitch
- **Background modes**: original, transparent or solid colour
- **One-click download**: HD PNG, transparent PNG, or copy the image straight to your clipboard
- **Dark mode**
- Runs fully in your browser, so your text is never uploaded to a server

## Run it locally

```bash
git clone https://github.com/wondermayank/wonder-typography.git
cd wonder-typography
python -m http.server 8000
```

Then open `http://localhost:8000`. Any static file server works.

## Deploy

- **Cloudflare Pages:** connect this repo, leave the build command empty and set the output directory to `/`.
- **Vercel:** import the repo. Framework preset: Other, no build command.
